# Subscription Pricing Page
This is a simple and clean **Subscription Pricing Page** built using **HTML** and **CSS**.  
The project displays three subscription plans — Free, Standard, and Premium — with styled pricing cards and feature comparison.

## Features
- Clean and modern UI design
- Three pricing cards (Free, Standard, Premium)
- Styled price headings
- Feature comparison list
- Check and cross icons for feature availability
- Card border styling and spacing
- Centered layout
- Simple and readable structure

## Technologies Used
- HTML5
- CSS3
- Flexbox (for layout alignment)
